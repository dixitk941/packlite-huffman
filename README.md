# PackLite

Huffman text compressor for a Design and Analysis of Algorithms mini project.

Paste notes, compress them with a min-heap Huffman tree, download a `.huf` file, and restore the original text.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5002/

The same compressor is published at https://dixitk941.github.io/packlite-huffman/

The written report is `PackLite_Huffman_Report.docx`.
